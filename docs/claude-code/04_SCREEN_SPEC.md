# Screen Spec

## Design Principle
피보호자 앱과 보호자 앱은 완전히 다른 톤을 가진다.

피보호자 앱:
- 큰 글씨
- 큰 버튼
- 적은 선택지
- 난색 기반 팔레트
- 색 + 아이콘 + 텍스트 3중 표현
- 깊이 1단계 우선

보호자 앱:
- 흰 배경
- 파란 포인트
- 일반 관리 앱처럼 깔끔한 UI
- 정보 밀도는 피보호자 앱보다 높아도 된다.

## 피보호자 첫 실행
화면:
- 앱 이름: 잘보이네
- 설명: 크게 보고 쉽게 쓰는
- 손이 스마트폰을 들고 있는 일러스트
- 일러스트 속 폰 화면이 시작 버튼을 대신한다: `눌러보세요 / 스마트폰이 쉬워져요`
- 누르면 `준비하고 있어요`가 약 0.5초 뜬 뒤 화면 선택으로 넘어간다
- 하단 카드: 가족 및 보호자분들은 / 여기를 눌러주세요

별도의 큰 `시작하기` 버튼은 두지 않는다. 일러스트 속 폰 화면이 그 자리를 대신한다.

## 보호자 시작
피보호자 첫 화면 하단 카드에서 들어온다.

화면:
- 제목: 부모님께 이런 걸 해드릴 수 있어요
- 설명: 연결은 몇 분이면 끝납니다.
- 혜택 카드 3개
  1. 부모님을 대신해 필요한 앱을 관리해 드릴 수 있어요 / 홈 화면 앱과 버튼 색을 원격으로 정리합니다
  2. 부모님과 쉽게 메시지와 사진을 주고받을 수 있어요 / 큰 글씨로 바로 보이는 가족 메시지
  3. 부모님의 폰 상태를 확인할 수 있어요 / 배터리 · 소리 · 인터넷 연결을 한눈에
- 카카오로 시작하기 (우선)
- 구글로 시작하기
- 약관 안내: 시작하면 서비스 이용약관과 개인정보 처리방침에 동의하게 됩니다

가입과 로그인을 나누지 않는다. 소셜 로그인은 첫 진입이 곧 가입이므로
`회원가입` 링크를 따로 두면 재설치한 보호자가 어느 쪽을 눌러야 할지 판단할 수 없다.
이메일 로그인은 두지 않는다.

## 화면 선택
카드 2개:
- 정말 쉬운 화면
- 자세한 화면

각 카드:
- 미리보기 이미지 또는 간단한 mock
- 큰 제목
- 짧은 설명
- 선택 버튼

선택 즉시 확정된다. 추가 질문은 없다.

## 정말 쉬운 화면
상단:
- 시간
- 날짜
- 진동/벨 상태

중앙:
- 2x2 큰 버튼
- 전화
- 문자
- 앨범
- 영상 보기

하단:
- 가족 연결 또는 자녀 이름 버튼
- SOS
- 더 보기

## 자세한 화면
상단:
- 시간
- 날짜
- 진동/벨 전환

중앙:
- 2열 버튼 배열
- 전화
- 문자
- 카카오톡
- 영상 보기
- 사진찍기
- 사진 보기
- 더 추가하기 슬롯

하단 탭:
- 첫 화면
- 설정
- SOS

## SOS 화면
버튼:
- 119
- 112
- 보호자 — 대표 보호자에게 전화. 번호는 보호자가 연결할 때 넣은 것을 쓴다
  (2026-10-26 구현). 가족이 없거나 번호를 안 넣었으면 눌리지 않고, 그 두
  경우는 서로 다른 문구를 보여준다

동작:
- 번호 선택 시 전화 앱을 연다.
- 즉시 전화하지 않는다.
- 사용자가 통화 버튼을 한 번 더 눌러야 한다.

## 보호자 대시보드
하단 탭:
- 홈 관리
- 메시지
- 안심
- 설정

상단 고정 카드:
- 현재 선택된 부모님 이름
- 마지막으로 폰을 쓰신 때 (안부 신호) — 없으면 `아직 / 연결되기 전이에요`
- 배터리 (카드 아래 목록)
- 소리 모드 (카드 아래 목록)
- 읽은 때 — 측정값의 나이. 체크인과 따로 움직인다
- ~~연결 상태~~ — 인터넷은 보고하지 않는다. 체크인이 도착했다는 사실이
  이미 같은 것을 증명하고, `ACCESS_NETWORK_STATE`를 아낀다

히어로 카드는 증거 없이 안심시키지 않는다. 서버는 폰이 열렸다는 것을 알지
부모님이 괜찮으신지는 모른다. 없는 체크인도, **오래된 체크인도** 올림하지
않는다.

가족 플랜일 때:
- 부모님 이름 드롭다운
- 엄마 김옥순
- 아버지 박영철
- + 부모님 추가

## 홈 관리 탭
기능:
- 현재 홈 버튼 목록
- 드래그 순서 변경
- 이름 수정
- 삭제
- 앱 추가
- 버튼 색상 변경
- 글씨 크기 변경
- 화면 모드 변경

## 메시지 탭
기능:
- 카톡 스타일 대화
- 텍스트 전송
- 이미지 전송
- 무료 잔여 횟수 표시 (보호자 쪽에만. 어르신에게 가족이 몇 번 더 쓸 수
  있는지 세어 보여주는 것은 가혹하고 그분 일도 아니다)
- 읽어드리기 — 받은 메시지를 소리로. 어르신 쪽에만
- 빠른 답장 — 「전화 좀 줘」「잘 있다」「고맙다」. 어르신 쪽에만
- 읽음 확인 — 보호자가 보낸 메시지에만. 어르신에게는 보여주지 않는다
- 유료 전환 안내

- 읽음 확인
