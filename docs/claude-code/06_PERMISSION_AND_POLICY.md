# Permission And Policy

## General Rule
권한은 필요한 순간에 요청한다. 피보호자에게 한 번에 많은 권한을 요구하지 않는다.

## MVP Initial Permission
첫 온보딩에서는 기본 런처 설정만 먼저 요청한다.

Do:
- 런처 설정 안내
- Android 기본 홈 앱 설정 팝업

Do not:
- 위치 권한 요청
- 전화 상태 권한 요청
- 알림 권한 요청
- 백그라운드 위치 권한 요청

## Notification Permission
알림 권한은 가족 연결 시점에 요청한다.

사용 목적:
- 가족 메시지
- 보호자 연결 알림
- 유료 기능 동의 요청

## Paid Permission Flow
안심 케어 결제 후 피보호자 동의가 필요하다.

1. 보호자 결제
2. 피보호자 폰에 동의 화면 표시
3. 피보호자가 허락
4. 시스템 권한 요청
5. 기능 활성화

거절 시:
- 안심 케어 기능 비활성화
- 보호자에게 거절 안내
- 결제 자동 환불 상태로 전환
- 무료 기능은 유지

## Location — MVP에서 제외 (2026-10-26)
위치 기능 전체를 뺐다. 이유는 `01_PRODUCT_PRD`의 `## 위치 기능을 뺀 이유`에
적었다. 요지는 세 가지가 겹쳤고 어느 하나도 돈이나 시간으로 풀리지 않는다는
것이다 — 경찰·119 절차가 더 낫고 공짜, Play 스토커웨어 조항, 위치기반서비스
사업 신고.

다시 넣게 될 경우를 위해 남겨 두는 제약:
- **위치가 단말 밖으로 나가면 방식과 무관하게 신고 대상**이다. 단말 GPS든
  통신사 API든, 체크인에 얹든 필요할 때만 읽든 같다. 면제는 단말에서만 쓰고
  서버로 보내지 않는 경우뿐이다.
- **푸시로 깨워서 읽는 길은 없다.** Android 문서가 명시한다 — 위치는
  while-in-use 권한이라 앱이 백그라운드이면 위치 포그라운드 서비스를 만들 수
  없고, **FCM 고순위 메시지 예외도 위치에는 적용되지 않는다.**
  `ACCESS_BACKGROUND_LOCATION`을 피할 방법이 없다.
- 그 권한은 Android 11부터 **앱이 띄우는 팝업으로 받을 수 없다.** 사용자가
  설정에 들어가 '항상 허용'을 직접 골라야 하고, 어르신에게 이 앱에서 가장
  어려운 동작이 된다.
- Play는 선언 양식과 **30초 이내 시연 영상**을 요구한다.
- 실시간 추적이라고 표현하지 않는다. (표현이 곧 동의 대상이므로 이 줄은
  기능이 돌아오든 아니든 유효하다.)

## Phone State
무료 기능으로 이동 (2026-10-26).

배터리와 벨소리 모드는 Android가 런타임 권한 없이 내준다. PRD의 무료 목록에
`폰 상태 앱 실행 시 1회 갱신`이 그대로 있고, 체크인이 하는 일이 정확히
그것이다. 유료로 남는 것은 **5분 주기 백그라운드 갱신**뿐이다.

- 인터넷 상태는 보고하지 않는다. `ACCESS_NETWORK_STATE`가 필요한데, 체크인이
  도착했다는 사실이 이미 같은 것을 증명한다.
- 벨소리는 퍼센트가 아니라 모드다. 무음 모드에서도 벨 볼륨은 100%일 수 있고,
  보호자가 묻는 것은 `왜 전화를 안 받으시지`다.

### 연락처에 없는 번호 통화 알림 — 삭제 (2026-10-20)
`READ_CALL_LOG`는 Play가 기본 전화·문자 앱에만 주고 이 앱은 런처다. 권한을
받을 가망이 없는 기능을 파는 셈이었다.

### 앱 설치 감지 알림 — 삭제 (2026-10-26)
성인의 설치 목록은 민감정보이고, Play 스토커웨어 조항이 겨냥하는 바로 그것이다.
얻는 것에 비해 위험이 크다.

## Installed Apps
유료 앱 설치 감지와 무료 앱 목록 읽기 모두 Android 정책 확인이 필요하다.

MVP 접근:
- 런처 앱으로서 설치된 앱 목록 읽기를 시도한다.
- 정책 리스크가 있으면 사용자 선택 앱만 등록하는 fallback을 준비한다.

## 소리 울리기 (삭제됨)
**2026-10-29 제품에서 뺐다.** 정책은 가장 깨끗한 기능이었다 - 부모님에 대해
아무것도 수집하지 않고 아무것도 가져오지 않으며, 원격으로 하는 일은 소리를
내는 것 하나였다. 뺀 이유는 정책이 아니라 두 가지다.

- 푸시는 앱이 화면에 떠 있을 때만 앱에 닿는다. 깨어 있는 폰은 울리고 자는
  폰은 울리지 않았는데, 자는 폰이 이 기능이 있던 이유 전부다. 백그라운드
  핸들러와 화면을 깨우는 네이티브 코드가 필요하고, Android 14의
  `USE_FULL_SCREEN_INTENT`는 런처에 기본으로 주어지지 않는다.
- 성인이 다른 성인의 폰을 소리 나게 만드는 앱의 전례를 찾지 못했다.

아래는 삭제 전 기록이다.

구현 제약:
- `STREAM_ALARM`으로 재생한다. 벨소리 무음·진동이 막지 못하는 유일한 스트림이고,
  알람 시계가 그렇게 동작한다. DND에서 알람까지 꺼둔 경우는 막히는데, 그걸
  넘으려면 `ACCESS_NOTIFICATION_POLICY`가 필요하고 어르신에게 요구할 만하지 않다.
- **볼륨은 건드리지 않는다.** 남의 알람 볼륨을 최대로 올려놓고 되돌리지 않으면
  다음 날 아침 여섯 시에 그 사람을 잡는다.
- **화면 아무 데나 누르면 꺼진다.** 60초 뒤 스스로도 꺼진다 — 폰은 다른 방
  가방 속에 있을 수 있고, 끝나지 않는 소리는 찾은 폰이 아니라 방전된 배터리다.
- 원격 발동은 FCM이 필요하다. `applicationId`는 2026-10-26에
  `com.jalboine.app`으로 확정했고, Firebase 등록은 아직 남아 있다.

### 기존 메모
유료 기능.

주의:
- OS 정책상 강제 재생은 제한될 수 있다.
- 실제 구현 전에는 interface와 UI만 분리한다.
- 권한/정책 문제 발생 시 일반 푸시 + 알림음 fallback을 둔다.

## SOS Call
무료 기능.

정책:
- 앱에서 바로 119/112로 전화하지 않는다.
- 전화 앱에 번호를 표시한다.
- 사용자가 통화 버튼을 한 번 더 눌러야 한다.
