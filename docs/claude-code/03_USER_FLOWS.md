# User Flows

## 0. 앱 실행 분기
앱을 열 때마다 먼저 어디로 보낼지 판단한다. 첫 화면은 이 판단이 모두 실패했을 때만 보인다.

1. 어르신 화면 모드가 저장되어 있으면 → 해당 홈 화면 (정말 쉬운 / 자세한)
2. 보호자로 로그인되어 있으면 → 보호자 대시보드
3. 둘 다 아니면 → 첫 화면

이 앱은 어르신 폰의 기본 런처가 되므로, 홈 버튼을 누를 때마다 첫 화면이 뜨면 안 된다.

1번 판단은 화면 모드 저장(Phase 2), 2번 판단은 로그인 상태(Phase 4)가 있어야 가능하다.
그 전까지는 두 판단 모두 실패로 두고 첫 화면으로 보낸다.

## 1. First Launch
1. 앱 실행
2. 첫 화면에서 역할 분기
3. 일러스트 속 폰 화면을 누르면 `준비하고 있어요`가 약 0.5초 뜬 뒤 피보호자 온보딩으로 이동
4. 하단 카드 `가족 및 보호자분들은 여기를 눌러주세요`는 보호자 시작 화면으로 이동

## 1-1. 보호자 시작
1. 혜택 3가지를 읽는다
2. `카카오로 시작하기` 또는 `구글로 시작하기`를 누른다
3. 계정이 없으면 그 자리에서 만들어지고, 있으면 로그인된다 — 사용자가 둘을 구분할 필요가 없다
4. 처음 온 보호자는 부모님 연결 화면으로, 이미 있던 보호자는 대시보드로 간다

재설치·기기 변경·로그아웃한 보호자도 같은 버튼으로 돌아온다.

## 2. 피보호자 온보딩
질문은 하지 않는다.

1. 화면 선택
2. `정말 쉬운 화면` / `자세한 화면` 미리보기
3. 선택 즉시 홈 화면 확정
4. 런처 설정 안내
5. Android 기본 런처 설정 시스템 팝업
6. 가상 홈 튜토리얼
7. 실제 홈 화면 진입

정말 쉬운 화면 기본 앱:
- 전화
- 문자
- 앨범
- 영상 보기

자세한 화면 기본 앱:
- 전화
- 문자
- 카카오톡
- 영상 보기
- 사진찍기
- 사진 보기

## 3. 정말 쉬운 화면
특징:
- 스크롤 없음
- 한 화면에 모든 핵심 기능
- 설정 메뉴 최소화
- 큰 버튼 4개 기본
- 가족 연결 버튼
- SOS 버튼

앱 추가:
- 보호자 원격 추가 가능
- 어르신은 `더 보기`에서 제한적으로 추가 가능

## 4. 자세한 화면
특징:
- 스크롤 가능
- 기본 앱 6개
- 추가 앱 슬롯 2개
- 하단 탭: 첫 화면 / 설정 / SOS

설정 탭:
- 앱 설정하기
- 글씨 크기 조절하기
- 가족 연결 설정/끊기
- 진동/벨소리 전환
- 잘보이네 사용하지 않기

## 5. SOS
바로 전화하지 않는다.

1. 사용자가 SOS 진입
2. 119 / 112 / 보호자 선택
3. 전화 앱에 해당 번호 표시
4. 사용자가 전화 앱에서 통화 버튼을 한 번 더 누름

## 6. 보호자 연결
경로 A: 보호자가 먼저
1. 보호자 로그인
2. 부모님 이름 입력, 연결 번호 생성
3. 문자 앱에 내용을 채워 연다 (보내기는 보호자가 직접)
   - 출시 전: 연결 번호 문자 한 통. 부모님 폰 앱은 직접 설치
   - 출시 후: ① 설치 링크 ② 연결 번호, 두 통 (`app_config.store_listed`로 켬)
4. 부모님이 앱을 열고 가족 연결 → 번호 입력
5. 부모님 폰에서 연결 동의

설치 링크로 자동 연결(Play install referrer)은 아직 만들지 않았다. 출시 후
업데이트로 넣는다. 그때도 번호 입력은 실패 시 길로 남는다.

경로 B: 부모님이 먼저
1. 부모님 폰에서 4자리 코드 생성
2. 보호자가 코드 입력
3. 보호자가 이름/전화번호 입력
4. 연결 완료

## 7. 기기 초기화 / 앱 삭제 / 재설치 복구
1. 부모님 폰에서 앱 삭제 또는 기기 초기화
2. 재설치 시 새 기기로 인식
3. 보호자 앱에서 `부모님 폰 다시 연결`
4. 일회용 복구 링크 또는 6자리 복구코드 생성
5. 부모님 폰에서 링크 클릭 또는 코드 입력
6. `딸 지영님이 기존 설정을 복구하려고 해요` 확인
7. 피보호자 승인
8. 기존 senior_profile에 새 senior_device 연결
9. 이전 기기 자동 해제

보호자 연결 전 무료 사용자라면 복구하지 않고 새로 시작한다.

## 8. 보호자 여러 명 초대
무료 기능.

1. 대표 보호자가 `가족 초대하기`
2. 연락처 선택 또는 초대 링크 발송
3. 초대받은 사람이 로그인
4. 대표 보호자가 승인
5. 가족 보호자로 추가

대표 보호자:
- 결제
- 환불
- 기기 재연결
- 가족 보호자 삭제
- 대표 보호자 변경

가족 보호자:
- 상태 확인
- 메시지
- 알림 수신
- 긴급 연락처 등록

## 9. 대표 보호자 변경
부모님 폰 승인이 필요하다.

1. 부모님 폰에서 가족 연결 설정
2. 보호자 바꾸기
3. 새 보호자 연결 코드 입력 또는 링크 승인
4. 부모님 폰에서 변경 확인
5. 대표 보호자 변경
6. 기존 보호자에게 알림
7. 기존 보호자는 기본 해제

## 10. Paid Consent
1. 보호자가 안심 케어 결제
2. 피보호자 폰에 유료 기능 동의 화면 표시
3. 피보호자가 허락하면 권한 요청 진행
4. 피보호자가 거절하면 기능 비활성화
5. 보호자에게 거절 안내
6. 결제는 자동 환불 처리
